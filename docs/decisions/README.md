# 아키텍처 결정 기록 (ADR)

중요한 기술 선택은 짧은 문서로 남깁니다. 파일명 규칙: `NNNN-짧은-제목-영문-케밥케이스.md` (예: `0001-terraform-cloud-remote-backend.md`).

## 템플릿

```markdown
# N. 제목

날짜: YYYY-MM-DD
상태: 제안됨 | 수락됨 | 폐기됨

## 맥락

문제나 제약이 무엇인지.

## 결정

무엇을 선택했는지.

## 결과

기대 효과와 트레이드오프.

## 대안

검토했으나 채택하지 않은 옵션.
```

번호는 시간 순으로 증가시킵니다.
